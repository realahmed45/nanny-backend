  NOTES — 5 things to do
═══════════════════════════════════════════════════════════════════════

1. REPLACE "YOUR-APP" (3 places)
   Two on Render (PUBLIC_BASE_URL, CORS_ORIGINS), one on Vercel
   (VITE_API_BASE). Deploy the backend first so you know its URL.

2. ROTATE THE DATABASE PASSWORD
   The old password was shared in chat, so treat it as public.
   Atlas -> Database Access -> edit user "ahmed" -> Edit Password.
   Put the new one in MONGODB_URI above, replacing ROTATE_THIS_PASSWORD.
   Also: Atlas -> Network Access -> Add IP -> 0.0.0.0/0
   (without this Render cannot reach the database at all)

3. BANK DETAILS — your real account
   Payments are manual transfers. The bot shows families these details
   and they send back a screenshot of the receipt, which you approve in
   the dashboard. So this must be the actual account you want customers
   paying into — I cannot invent it.

   BANK_NAME           the bank, e.g. "Meezan Bank"
   BANK_ACCOUNT_NAME   the account holder name
   BANK_ACCOUNT_NUMBER the account number
   BANK_IBAN           optional, leave empty if you do not use IBAN

   If these are blank the bot tells families to contact support instead
   of showing an empty block, so nothing breaks — but nobody can pay.

4. RESEND_API_KEY - sends the verification codes

     a. resend.com -> API Keys -> Create API Key
     b. Copy it (starts with "re_") and paste above

   The From address is already set to your verified domain
   (futurelifebali.com), so emails reach anyone.

   Note: email CANNOT be sent from a Gmail address. Google's DNS forbids
   other services sending as gmail.com, so those messages are rejected or
   land in spam. RESEND_REPLY_TO is set to your Gmail instead, so anyone
   who replies still reaches your normal inbox.

5. CURRENCY — check this one
   Transport fee is 50,000-100,000 per your spec, which is not a USD
   range. With CURRENCY=USD the bot quotes families "50,000 USD".
   Set it to whatever your market actually uses (PKR, IDR, VND...).
